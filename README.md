
# Automated Landing Page using AI (Wix ADI)

## Project Overview
This project demonstrates the creation of an automated landing page using AI-powered Wix ADI.  
The project focuses on rapid website development, automation, and responsive UI design using no-code tools.

## Tools Used
- Wix ADI (Artificial Design Intelligence)
- AI Website Builder
- UI/UX Design Principles
- No-Code Development Tools

## Features
- AI-driven automated page creation
- Fully responsive design
- Smart layout and content generation

## Project Steps
1. Selected business category and requirements in Wix ADI
2. Generated landing page using AI automation
3. Customized layout, content, and visuals
4. Published and tested the website
