
# Automated Landing Page using AI (Wix ADI)

## Project Overview
This project demonstrates building an automated landing page using AI-powered Wix ADI.

## Tools Used
- Wix ADI
- AI Website Builder
- UI/UX Design
- No-code tools

## Features
- Automated page creation
- Responsive design
- AI-based layout generation

## Project Steps
1. Selected business type in Wix ADI
2. Generated landing page using AI
3. Customized layout and content
4. Published the website
